# 🎓 Lesson Listener — Розумний AI-суфлер для онлайн-уроків

Швидкий, непомітний та точний асистент для уроків у **Google Meet**, **Zoom** та інших платформах. Слухає запитання вчителя через аудіопотік системи або мікрофон і за **1-2 секунди** виводить покрокову відповідь та готову шпаргалку.

---

## ⚡ Швидкий старт для друзів

### 1. Встановлення (в 1 клік)
Запусти файл **`install.bat`**. Він автоматично:
- Створить віртуальне середовище Python (`.venv`)
- Встановить усі необхідні бібліотеки (`requirements.txt`)

### 2. Запуск
Запусти файл **`run.bat`**.  
З'явиться плаваючий компактний віджет, який можна закріпити поверх усіх вікон або згорнути в системний трей.

### 3. Налаштування API-ключа
Натисни на шестерню (**⚙**) у правому верхньому кутку віджета та введи свій безкоштовний ключ:
- **Google Gemini** (рекомендовано — прямий аналіз аудіо, 500 запитів/добу безкоштовно): [Google AI Studio](https://aistudio.google.com/app/apikey)
- **OpenRouter** (NVIDIA Nemotron 3 Ultra 550B, Gemma 4): [OpenRouter](https://openrouter.ai/)
- **Groq Cloud** (швидкість < 0.5 с): [Groq Console](https://console.groq.com/)

## 🎮 Гарячі клавіші та керування

| Дія | Клавіша / Кнопка | Опис |
|---|---|---|
| **Отримати відповідь** | **`F8`** (або синя кнопка) | Миттєво аналізує останні секунди промови вчителя і видає точну відповідь |
| **Режим перерви** | **☕** (у верхньому барі) | Зупиняє запис звуку та роботу ШІ на зміні (квота запитів не витрачається) |
| **Міні-режим** | **🗕** | Згортає віджет до мініатюрної смужки |
| **Поверх усіх вікон** | **📌** | Закріплює вікно поверх браузера / Zoom |
| **Налаштування** | **⚙** | Вибір предмета, вчителя, аудіопристрою, розкладу та провайдера |

---

## ✨ Ключові фічі

1. **Красивий математичний вивід:**
   - Жодних сирих LaTeX-кодів (`\sqrt`, `^2`, `\frac`)! Усі вирази автоматично перетворюються на читабельний вигляд: `²`, `³`, `√(a² + b²)`, `·`, `±`.
   - Окремий виділений блок **⚡ Шпаргалка** з головними даними задачі ($k$, $b$, корені, формули).

2. **Розклад уроків та перерв:**
   - Віджет знає розклад дзвінків і уроків: показує час до кінця поточного уроку та який урок буде наступним.
   - Під час перерви автоматично переходить у режим відпочинку з іконкою ☕. При натисканні `F8` автоматично повертається до уроку.

3. **22 попередньо налаштовані предмети:**
   - Алгебра, Геометрія, Фізика, Хімія, Біологія, Історія України, Всесвітня історія, Правознавство, Англійська мова, Українська мова та література, Технології, STEM тощо.
   - Підтримка персональних звернень до вчителів на ім'я та по батькові.

4. **Абсолютна приватність:**
   - Ключі та персональні налаштування зберігаються суто локально у файлі `config.json` і нікуди не передаються.
