# 🎓 Lesson Listener — Розумний AI-суфлер для онлайн-уроків

Швидкий, непомітний та точний асистент для уроків у **Google Meet**, **Zoom**, **Сферум / VK Teams**, **Яндекс Телеміст**. Слухає запитання вчителя через аудіопотік системи або мікрофон, аналізує виділені завдання з екрана та за **1-2 секунди** виводить покрокову відповідь і готову шпаргалку.

---

## ⚡ Швидкий старт для друзів

### 1. Встановлення (в 1 клік)
Запусти файл **`install.bat`**. Він автоматично:
- Створить віртуальне середовище Python (`.venv`)
- Оновить `pip` та встановить усі необхідні бібліотеки (`requirements.txt`)

### 2. Запуск
Запусти файл **`run.bat`**.  
З'явиться плаваючий компактний віджет, який можна закріпити поверх усіх вікон або згорнути в системний трей.

### 3. Налаштування API-ключа
Натисни на шестерню (**⚙**) у правому верхньому кутку віджета та введи свій ключ:
- **Google Gemini** (рекомендовано — прямий мультимодальний звук і картинки, 500 запитів/добу безкоштовно): [Google AI Studio](https://aistudio.google.com/app/apikey)
- **OpenRouter** (NVIDIA Nemotron 3 Ultra 550B, Gemma 4, Qwen VL): [OpenRouter](https://openrouter.ai/) — працює скрізь без обмежень
- **Groq Cloud** (швидкість < 0.5 с): [Groq Console](https://console.groq.com/)

> 💡 **Для користувачів з РФ (обхід блокування Gemini):**  
> Google блокує доступ до Gemini API з російських IP (помилка 403 Forbidden).  
> У Lesson Listener передбачено два рішення:
> 1. Введіть локальний проксі у налаштуваннях: `http://127.0.0.1:10809` (v2ray / clash / VPN).
> 2. Або просто вкажіть безкоштовний ключ **OpenRouter** чи **Groq** — додаток автоматично перемкнеться на них при будь-якій помилці доступу до Gemini.

### 4. Швидке перенесення розкладу через ШІ (для лінивих 🤖)
Не хочеш вручну набивати розклад дзвінків та уроків?  
Просто закинь фото свого щоденника або електронного журналу в будь-який ШІ (ChatGPT, DeepSeek, Claude, Antigravity) — він заповнить файл за 5 секунд!  
👉 **Детальна інструкція та готовий промпт-шаблон:** [AI_SCHEDULE_IMPORT.md](AI_SCHEDULE_IMPORT.md)

## ✨ Ключові фічі

1. **Аналіз екрана в реальному часі (Vision `F9`):**
   - Натисни **`F9`** або 📷 в будь-який момент (навіть коли суфлер згорнутий).
   - Затисни ЛКМ та обведи прямокутником формулу, графік, геометричне креслення або тест із варіантами (А, Б, В, Г).
   - Підтримка екранів з будь-яким масштабуванням Windows (High-DPI 100%, 125%, 150%, 200%) — жодних зсувів.
   - Якщо вчитель у цей момент коментував задачу голосом — аудіо автоматично передається разом із зображенням.

2. **Повна підтримка Zoom, Google Meet та Сферум:**
   - Автоматичне відкриття уроку натисканням однієї кнопки **🌐**.
   - Підтримка протоколів `zoommtg://`, `https://zoom.us/j/...`, Яндекс Телеміст та Сферум / VK Teams.
   - Захист від повторного відкриття: якщо урок уже відкрито у вікні або триває довше 3 хвилин, повторного відкриття сторінки не відбувається.

3. **Голосове сповіщення про уроки (SAPI TTS):**
   - На початку уроку за розкладом Windows приємним голосом оголошує: *«Начало урока: [Предмет]. Время [ЧЧ:ММ]»*.
   - Інтеграція в автозавантаження Windows (`shell:startup`) зі стартом у системному треї (`--tray`).
   - Ярлики в меню «Пуск» та на Робочому столі.

4. **Адаптація для шкільної програми України та РФ:**
   - Перемикач мови підказок: **Авто** (визначає за мовою уроку), **Русский (RU)**, **Українська (UK)**.
   - Попередньо налаштовані профілі предметів РФ: **Русский язык** (орфограммы, морфологический разбор), **Литература** (анализ, тропы), **История России**, **Обществознание**, **ОБЖ / ОБЗР**, **Труд / Технология**, **Информатика** тощо.
   - Предмети програми України: Алгебра, Геометрія, Фізика, Хімія, Біологія, Історія України, Всесвітня історія, Правознавство тощо.

5. **Красивий математичний вивід:**
   - Жодних сирих LaTeX-кодів (`\sqrt`, `^2`, `\frac`)! Усі вирази автоматично перетворюються на читабельний вигляд: `²`, `³`, `√(a² + b²)`, `·`, `±`.
   - Окремий виділений блок **⚡ Шпаргалка** з головними даними задачі ($k$, $b$, корені, формули).

6. **Розклад уроків та перерв:**
   - Віджет знає розклад дзвінків і уроків: показує час до кінця поточного уроку та який урок буде наступним.
   - Під час перерви автоматично переходить у режим відпочинку з іконкою ☕. При натисканні `F8` автоматично повертається до уроку.

7. **Ізоляція звуку від Discord:**
   - Натисни кнопку **«🎛️ Розділити звук у Windows»** у налаштуваннях звуку (⚙).
   - У вікні Windows направ вивід **Google Chrome / Zoom** на віртуальний кабель (`CABLE Input`), а **Discord** залиш на навушниках.
   - У Lesson Listener обери **CABLE Input [Loopback]** — додаток буде чути 100% тільки вчителя і 0% друзів із Discord.
   - Навіть при спільному звуковому потоці вбудовані ШІ-фільтри автоматично ігнорують розмови та репліки з Discord.

8. **Абсолютна приватність:**
   - Ключі та персональні налаштування зберігаються суто локально у файлі `config.json` (який додано в `.gitignore`) і нікуди не передаються в мережу.
