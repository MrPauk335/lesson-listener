# 🤖 Инструкция для ленивых: Как перенести расписание в Lesson Listener через ИИ

Если тебе лень вручную настраивать расписание уроков и звонков — переложи это на любой ИИ (ChatGPT, DeepSeek, Claude, Google Gemini, Antigravity, OpenCode, Cursor или Telegram-бота).

ИИ сделает всё за 5 секунд: распознает фото дневника, скриншот из электронного журнала (Дневник.ру, МЭШ, Сферум, Новые Знания) или скопированный текст из чата класса.

---

## Вариант 1. Если ты используешь ИИ-редактор (Antigravity, Cursor, OpenCode, Claude Code)

Ты можешь просто скинуть файл или фото прямо в чат с агентом:

1. Перетащи фото/скриншот расписания в чат (или скопируй текст из мессенджера).
2. Напиши агенту одну строчку:
   > **«Посмотри на это расписание и заполни файл `schedule.json`. Если на фото есть ссылки на Zoom/Meet или имена учителей — обнови соответствующие файлы в папке `profiles/`.»**
3. Агент сам отредактирует `schedule.json` и нужные профили. Готово!

---

## Вариант 2. Если ты используешь веб-ИИ (ChatGPT, DeepSeek, Claude, Gemini)

1. Открой диалог с любой нейросетью (ChatGPT, DeepSeek, Claude и др.).
2. Прикрепи **фото / скриншот** расписания (или вставь текст).
3. Скопируй и отправь промпт, написанный ниже:

```text
Привет! Я использую программу Lesson Listener (ИИ-суфлер для онлайн-уроков).
Мне нужно заполнить файл конфигурации расписания schedule.json по моим данным.

Вот фото / текст моего расписания (прикрепляю).

Сформируй для меня СТРОГО валидный JSON-код для файла schedule.json в следующем формате:
{
  "enabled": true,
  "auto_switch_subject": true,
  "auto_recess": true,
  "auto_open_meet": true,
  "detect_from_windows": true,
  "detect_from_audio": true,
  "bells": [
    {"num": 1, "start": "08:30", "end": "09:15"},
    {"num": 2, "start": "09:25", "end": "10:10"},
    {"num": 3, "start": "10:20", "end": "11:05"},
    {"num": 4, "start": "11:30", "end": "12:15"},
    {"num": 5, "start": "12:40", "end": "13:25"},
    {"num": 6, "start": "13:45", "end": "14:30"},
    {"num": 7, "start": "14:40", "end": "15:25"},
    {"num": 8, "start": "15:35", "end": "16:20"}
  ],
  "timetable": {
    "Monday": ["algebra", "geometry", ...],
    "Tuesday": [...],
    "Wednesday": [...],
    "Thursday": [...],
    "Friday": [...],
    "Saturday": [],
    "Sunday": []
  }
}

Правила сопоставления ID предметов (используй точные названия):
- Алгебра -> "algebra"
- Геометрия -> "geometry"
- Физика -> "physics"
- Химия -> "chemistry"
- Биология -> "biology"
- Русский язык -> "rus_lang"
- Литература -> "rus_lit"
- История России -> "history_ru" (или "world_history" для Всеобщей истории)
- Обществознание / Право -> "law" или "civic_ed"
- Английский язык -> "english"
- Информатика -> "informatics"
- География -> "geography"
- Физкультура -> "pe"
- ОБЖ / ОБЗР -> "health"
- Труд / Технология -> "technologies"
- ИЗО / Мистецтво -> "art"
- Українська мова -> "ukr_lang", Українська література -> "ukr_lit", Історія України -> "history_ua"
(Если урока нет или окно — ставь пустую строку "")
(Время звонков в "bells" настрой строго под время из моего расписания)

Выведи только чистый JSON-блок без лишних рассуждений.
```

4. Скопируй полученный JSON-код из ответа ИИ.
5. Открой файл **`schedule.json`** в папке `lesson_listener` (через Блокнот или любой редактор), нажми `Ctrl + A` → `Ctrl + V` → `Ctrl + S`.
6. Перезапусти приложение — расписание сразу подхватится!

## 🔗 Как добавить постоянные ссылки на Google Meet / Zoom

Если у твоих учителей постоянные ссылки на конференции:
В папке **`profiles/`** для каждого предмета есть файл (например, `algebra.json`, `geometry.json`, `physics.json`).

Ты можешь просто сказать ИИ:
> **«Вот список ссылок на уроки от учителей: [вставить ссылки]. Обнови поля `"meet_url"` в соответствующих файлах `profiles/*.json`.»**

Пример содержания `profiles/algebra.json`:
```json
{
  "id": "algebra",
  "name": "📐 Алгебра",
  "meet_url": "https://meet.google.com/abc-defg-hij",
  "teacher_name": "Иванова Мария Ивановна"
}
```
После этого суфлёр будет сам открывать нужный урок по расписанию по нажатию кнопки **🌐** или голосом оповещать о начале урока!
